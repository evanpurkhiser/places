# V0.5 - Import Existing Saved Places

Individual Google Maps place links, including identifier-bearing Takeout links,
and `gmaps:<place_id>` inputs are supported. Imports reuse existing places and can
apply existing tags and notes, allowing automation to preserve list context as
tag assignments.

Built-in list/archive ingestion, batch progress, and source records for an import
remain planned. See [Google Maps imports](../../README.md#google-maps-imports) for
current commands and [sources](../sources.md) for the discovery-context model.
