# V2 - Contextual Filtering

Implemented contextual filters include geographic radius, map rectangles,
directional sectors, and opening hours. Named point strings resolve through
Google Places. `open` accepts local clock/weekday values and absolute instants,
with continuous intervals specified using `for` or `until`.

Remaining work includes area boundaries, saved geographic references, route
corridors, holiday/secondary hours, and query explanations. Travel-time budgets,
detours, and open-on-arrival remain exploratory routing features. See the
[search grammar](../search-grammar.md) and [time values](../time-values.md).
