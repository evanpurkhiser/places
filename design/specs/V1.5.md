# V1.5 - Filter Foundations

The shared parser and typed filter engine implement boolean composition, groups,
negation, strings, wildcards, named arguments, and structured diagnostics. Tag,
text, and presence predicates run through the API, CLI, and web query input.
Tags have normalized names with an optional namespace, such as `type.cafe`.

`places docs filter` describes executable capabilities from the server registry.
The [grammar status](../search-grammar.md#implementation-status) tracks geographic,
hours, and planned registrations. Saved queries and query explanations remain
future work.
